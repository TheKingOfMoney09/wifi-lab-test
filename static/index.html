Pasul 2 (o singura data pe acest laptop): puterea semnalului WiFi

Browserul nu poate citi puterea reala a semnalului WiFi din Windows, de aceea e nevoie de un mic test separat. Descarca arhiva, dezarhiveaz-o (click dreapta → Extract All), apoi fa dublu-click pe run_wifi_test.bat din interior. Scriptul citeste semnalul real cu netsh si il trimite automat catre acest server.

Daca Windows sau browserul arata un avertisment despre fisierul descarcat, este normal pentru fisiere .bat/.ps1 — alege "Pastreaza" / "Ruleaza oricum" (fisierul vine de la profesor, din reteaua locala a laboratorului).
